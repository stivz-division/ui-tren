# Выполнение тренировок

Источник требований: запрос пользователя и локальный `api-tren/openapi.json` от 2026-09-13.

Архитектура: Nuxt 4 / Vue 3, существующие feature slices и BFF. Все mutations принимают возвращённую сессию как authoritative state. Черновики полей существуют отдельно, только в памяти. Nuxt UI Carousel обеспечивает свайпы без новой зависимости.

- [x] API: разрешить только документированные методы и пути; добавить typed adapters с телом sets для save/complete и cursor history.
- [x] Подготовка: `/workout-session/prepare?programId=…`, список упражнений, модальный редактор подходов с save/cancel. Сохранение всей программы PUT, запуск только после подтверждения.
- [x] Выполнение: `useActiveWorkoutSession` — восстановление и server state; `useWorkoutExecution` — drafts, очередь сохранений и переходы; `WorkoutExerciseCard` — один слайд; `WorkoutExecutionScreen` — композиция и завершение/отмена.
- [x] Главная: GET active при открытии/resume, предложение продолжить независимо от расписания дня.
- [x] История: отдельный slice, cursor pagination, терминальные статусы и раскрываемые результаты; третья вкладка.
- [x] Проверки: allowlist, adapters, порядок и ошибки автосохранений; Playwright подготовка, редактирование, свайпы, complete/skip/reopen/cancel, восстановление и pagination на mobile viewport; lint, typecheck, unit, build.
- [x] Обновить карту проекта и API reference.

Границы компонентов: общий `SetEditor` принимает строковые строки подходов и сообщает новый массив через update:modelValue. Модальный редактор программы владеет отдельным черновиком. Карточки упражнений получают draft и статус, сообщают edits/actions. History card получает неизменяемую завершённую сессию.

Надёжность: каждый валидный ввод ставит отдельный snapshot в последовательную очередь. Невалидный промежуточный ввод сохраняется локально и показывает ошибку. Ответ старого запроса не заменяет более новый draft. После ошибки очередь прекращается; повторное сохранение явно инициирует пользователь после чтения актуального состояния. Завершение запрещено при pending упражнениях или несохранённых данных. Отмена тренировки требует подтверждения.
