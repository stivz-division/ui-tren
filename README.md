# UI Tren

Mobile-first frontend Telegram Mini App для недельного расписания тренировок. Приложение построено на Nuxt 4, Vue 3 и Nuxt UI; Laravel API работает как отдельный внешний сервис.

Реализованы главная с состояниями тренировки/отдыха, CRUD программ, подготовка и выполнение тренировок, восстановление активной сессии и история результатов. Перед запуском можно изменить подходы программы; во время выполнения фактические подходы сохраняются автоматически при каждом валидном изменении. Упражнения доступны по свайпу и номеру, их можно завершить, пропустить или открыть снова. Отмена тренировки требует подтверждения.

Из истории доступен анализ: план и факт и рекомендации. Блоки заключения и контекста истории временно скрыты в интерфейсе. На подготовке рекомендации последней сессии выбранной программы можно применить или отклонить до старта. Применение меняет будущий план, сохраняя историю и снимок активной тренировки. Незавершённые этапы автоматически перечитываются только на открытом видимом экране; «Обновить» не запускает повторную генерацию. Ограничения API описаны в [контракте](.ai-factory/references/api-tren-contract.md#анализ-и-рекомендации-2026-09-22).

## Локальный запуск

```bash
pnpm install
cp .env.example .env
pnpm dev
```

Приложение будет доступно на `http://localhost:3000`.

Для запуска вне Telegram можно задать в `.env` непустой `TELEGRAM_INIT_DATA`. При `APP_ENV=local` Nuxt BFF использует это значение вместо browser `initData` только в серверном запросе к Laravel. Fixture не попадает в client bundle, логи или persistent browser storage.

## Docker

```bash
cp .env.example .env
docker compose up --build
```

Compose запускает только Nuxt UI. Адрес Laravel API задаётся переменной `NUXT_API_BASE`; для Laravel на хост-машине используйте `http://host.docker.internal:8000/api`.

## Каталог упражнений

Справочник `/exercises` доступен из нижней навигации и поддерживает поиск по названию. Каталог загружается через `GET /api/exercises` (`id`, `code`, `name`, nullable `description` и `video_url`). Общий модуль `features/exercises` обслуживает справочник и выбор упражнений в программах.

Кнопка информации в активной тренировке, карточка справочника и кнопка в рекомендации замены открывают общее окно с описанием и видео через `GET /api/exercises/{id}`. YouTube отображается встроенным плеером с превью без автозапуска; прямые MP4/WebM/OGV — нативным video. Другие HTTP(S)-ссылки доступны через «Открыть видео». Плеер удаляется при закрытии окна. Дополнительный пакет не используется; воспроизведение и превью YouTube зависят от доступности сервиса и разрешения автора на встраивание.

При временной ошибке UI предлагает повторить запрос; для ранее сохранённого неизвестного `exercise_id` используется подпись «Упражнение №10». Каталог в frontend не захардкожен.

## Проверки

```bash
pnpm format:check
pnpm typecheck
pnpm lint
pnpm test:unit
pnpm test:e2e
pnpm build
```

Playwright проверяет ширины 320, 375 и 430 px. Для локального E2E нужен установленный Google Chrome.
